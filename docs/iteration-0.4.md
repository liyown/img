## 图片工具收敛与预览性能（2026-09-08，开发分支）

桌面通过左侧「转换与压缩」「尺寸与裁剪」直接进入，去掉「图片工具」父级和页内标签。每次只处理一张图片；打开文件只允许单选，拖放多个文件或文件夹会提示选择一个图片文件。两个入口保留同一张图片与参数，更换图片时重置裁剪、旋转和翻转。移除批量入口、文件/结果列表及标注、切分、拼接、水印编辑控件；旧预设若包含已移除操作，不在桌面列表中展示或隐式执行。图库详情提供两个单图处理入口，批量菜单不再提供处理入口。
