# img 0.4 实施与验收

图床管理优先，交付统一远端图库、独立图片工具、WebDAV/S3 跨设备同步和迁移引用修复。此文件记录实际完成状态，不代表稳定版已提供这些能力。

- [ ] M0：旧版窗口与恢复验收（四架构 Desktop CI 已通过）
- [ ] M1：SQLite 目录、历史迁移、缓存分离与统一图库
- [ ] M2：远端索引、跨设备同步、冲突与批量管理
- [ ] M3：独立图片处理、批量导出与上传
- [ ] M4：跨图床迁移、Markdown 引用修复

约束：图片允许本地缓存但不作为远端状态依据；同步只包含配置、图床密钥、索引和预设，不包含缓存、任务、本机路径或同步后端自身凭据。用户选择不额外加密同步数据。原始图片和已有远端对象不自动覆盖或删除。

开发采用功能提交，稳定版仅在全部验收后发布。

已执行：工作区测试通过（新增备份测试之前）；随后 img-records 17 项测试通过，工作区 Clippy（all-targets，warnings deny）通过。新增回归覆盖相同版本扫描保留已验证身份、排除目录不误判缺失、打开图库时拒绝恢复，以及不包含缓存的数据库备份恢复。原生界面和真实服务验收仍待完成。

验证：两套隔离数据目录分别连接本地 WebDAV 与 S3 模拟服务，通过并发字段冲突、解决后收敛、重复拉取、损坏批次、忽略条件写入拒绝同步，以及真实图库记录/隐藏状态同步测试；断言缓存图片不传输。凭据测试使用内存钥匙串替身，尚未以真实图床账号完成验收。图片工具、迁移与引用维护，以及完整图库操作/界面验收仍未交付。
