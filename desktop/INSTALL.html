安装 img

macOS 13 及以上。Apple silicon 请选择 arm64，Intel 请选择 x86_64。安装后无需 Rust、Go 或其他开发工具。

1. 安装应用

打开 DMG，将 Img.app 拖到 Applications，然后从应用程序打开 img。ZIP 用户先解压，再将 Img.app 移入应用程序。也可从包内打开 img，在「设置 → 关于与更新」点击「安装到应用程序并重新打开」，安装到个人的 ~/Applications。

2. 首次允许打开

社区版使用 ad-hoc 签名，未经过 Apple Developer ID 签名及公证。仅在确认文件来自本项目 GitHub Releases 时继续。

若 macOS 提示无法验证开发者，先关闭提示，再到「系统设置 → 隐私与安全性」，找到 img 的拦截信息，点击「仍要打开」并按系统提示确认。Apple 官方说明。

无需关闭 Gatekeeper、SIP，也无需在终端移除隔离属性。若系统明确提示恶意软件，请停止安装并重新核对来源。

3. 配置并上传

在「设置 → 存储源」添加自己的图床并设为默认。复制一张图片后按 ⌘⌥U，上传成功自动复制链接；⌘⌥S 截图并上传。链接格式在设置中选择。凭据、图库和上传队列保存在应用之外，升级会保留。

4. 安装后续更新

在「设置 → 关于与更新」检查更新，也可开启每天自动检查。下载后点击「退出并安装更新」：应用先验证安装包和应用、保存队列，再退出、替换并重新打开。目录不可写时可点击「手动安装」，退出旧版后在 Finder 替换。未公证的新版可能仍需在系统设置中允许打开。

CLI 已内置，无需单独下载。「添加终端命令」可建立 ~/.local/bin/img 入口，随应用升级。

English

Drag Img.app into Applications. This community build is ad-hoc signed and not notarized. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway after verifying the download source. Never disable system protections. Configure a default storage provider, then use ⌘⌥U to upload your clipboard and copy the resulting link. Updates are available in Settings → About; configuration and library data are preserved.
