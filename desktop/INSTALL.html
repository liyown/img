安装 img 社区版

原生桌面应用内置同版本 CLI，无需 Rust、Go 或其他编译工具。请从官网固定安装入口获取适合系统的最新版本。

macOS 13+

Apple silicon 选择 arm64，Intel 选择 x86_64。打开 DMG，将 Img.app 拖入 Applications；ZIP 先解压再移动应用。也可从应用「设置 → 关于与更新」安装到个人 ~/Applications。

社区版使用 ad-hoc 签名，未经过 Apple Developer ID 签名及公证。确认来自官方 GitHub Releases 后，如首次打开被阻止，到「系统设置 → 隐私与安全性」选择「仍要打开」。Apple 说明。无需关闭系统保护。

Windows x64

运行 EXE 安装向导，默认安装到当前用户目录。ZIP 可解压后运行 img-desktop.exe，保留同目录 img.exe。社区包未进行代码签名；系统提示未知发布者时先核对下载来源与 SHA-256，再按系统提供的选项继续。

Linux x64

支持 Ubuntu 24.04 / Debian 13 或更新版本。运行 sudo apt install ./img-desktop_*.deb 安装，然后从应用菜单打开。需要图形桌面、Vulkan 驱动和已解锁的 Secret Service（例如 GNOME Keyring）。

配置与快捷上传

在「设置 → 存储源」添加自己的图床并设为默认。macOS 按 ⌘⌥U 上传剪贴板、⌘⌥S 截图上传；Windows / Linux 使用 Ctrl+Alt+U / Ctrl+Alt+S。上传成功自动复制所选格式的链接。Windows 当前截取全屏；Linux 截图需要系统截图工具，全局快捷键需要 X11，Wayland 可使用窗口入口。菜单栏后台入口仅在 macOS 提供。

更新与 CLI

「设置 → 关于与更新」检查后续版本，也可开启每日自动检查。下载通过校验并保存队列后，macOS 退出、替换并重新打开，Windows 打开安装向导，Linux 请求系统授权安装。配置和图库保留。也可手动安装；未公证的 Mac 新版可能需要再次允许打开。

GUI 内置 CLI，「添加终端命令」可启用入口。只需要命令行时可从官网选择独立 CLI，支持 macOS / Linux 的 arm64 和 x64，以及 Windows x64。

English

macOS: drag Img.app to Applications. This community build is ad-hoc signed and not notarized; verify the source and use Privacy & Security → Open Anyway if blocked. Windows x64: run the EXE installer or extract the portable ZIP. Linux x64: install the DEB with apt on Ubuntu 24.04 / Debian 13+. Configure a default storage provider. Updates are available in Settings → About, preserving configuration and library data. The standalone CLI is also available for all three systems.
