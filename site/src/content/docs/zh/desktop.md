本文介绍已发布稳定版。主分支新增的统一图库、深色主题、文件夹导入及远端管理见[迁移与资料管理](/img/docs/workflows/)，这些能力尚未全部完成发行验收。

## 导入与上传

主窗口支持文件选择、拖放、剪贴板、截图和多行图片 URL。导入只加入待上传队列，点击「上传」才开始。每批在启动时固定存储源、处理选项与复制偏好。

真实传输进度来自请求体读取量；传输完成后显示等待确认，收到存储服务成功响应才标为完成。可暂停、继续、取消单项或整批，并重试失败项。暂停会终止请求，继续时重新上传文件，**不支持断点续传**。

## 图库与链接

图库只展示成功记录，支持网格和列表；历史记录保留已结束的上传。搜索文件名、存储源或 URL。点击缩略图可放大，Esc 关闭。

复制可选择纯链接、Markdown 图片、Markdown 链接、HTML 和 BBCode。默认自动复制当前批次的成功链接，按导入顺序换行排列。清理记录只删除应用内副本与记录，保留原文件和远端图片。

## 设置分区

| 区块           | 可以调整                                                   |
| -------------- | ---------------------------------------------------------- |
| 存储源         | 新增、编辑、测试、默认图床、凭据                           |
| 上传与图片处理 | 并发、重试、压缩、最大宽度、JPEG EXIF 清理、路径和同名处理 |
| 链接与剪贴板   | 复制格式、自动复制                                         |
| 应用偏好       | 快捷键与界面偏好                                           |
| 关于与更新     | 版本、诊断、添加 CLI 入口、手动检查更新                    |

稳定版尚无深色主题、远端图库管理、标签或文件夹导入。主分支的已实现功能与未交付范围见上述开发文档。

## 窗口与快捷操作

关闭窗口或 ⌘W 会隐藏窗口，上传继续；⌘Q 才退出。上传中退出可选择等待完成或暂停并退出。菜单栏提供打开窗口、上传剪贴板、截图上传、暂停／继续和退出。

| 快捷键 | 行为                 |
| ------ | -------------------- |
| ⌘U     | 选择图片，加入队列   |
| ⌘V     | 从剪贴板导入         |
| ⌘⇧S    | 截图并加入队列       |
| ⌘F     | 搜索                 |
| ⌘B     | 收起／展开侧栏       |
| ⌘⌥U    | 全局：直接上传剪贴板 |
| ⌘⌥S    | 全局：截图并直接上传 |

全局快捷键可修改或关闭。快捷批次顺序执行，不会顺带上传尚未手动提交的图片。未设置默认源时保留导入内容并打开存储设置；取消截图不创建任务。每批结束后发送一条结果通知。

全局快捷键实际触发、第三方快捷键冲突、系统截图取消、状态栏点击，以及通知授权和点击响应仍需人工验收。0.3.0 的测试进展以[验收记录](https://github.com/liyown/img/blob/main/stability-qa.md)为准。

## 安装、终端命令与更新

macOS 从 DMG 打开正式 Img.app 后，可拖入 Applications，或在「关于与更新」选择「安装到应用程序并重新打开」，后者安装到当前用户的 `~/Applications/Img.app`。开发与验收应用不提供此入口，请从[安装页](/img/install/#gui)获取正式包。

「添加终端命令」默认写入 `~/.local/bin`；已有其他 img 命令时不会覆盖。终端找不到命令时，将该目录加入 PATH，或选择独立 CLI 安装器。Windows 默认使用当前用户的 Programs/img 目录。

「检查更新」仅检查稳定桌面版本。下载后核验架构、大小和 SHA-256；无法验证时不会自动安装。社区包更新后仍可能需要系统允许打开。

## 本地数据与恢复

数据保存在 `~/Library/Application Support/aperture`，沿用历史目录保证升级保留。包含队列、图片副本、缩略图与偏好。一个目录同一时间只允许一个进程。

队列串行原子保存，保留最近两份有效备份。发现损坏后先选择恢复备份，或保留损坏文件并重建空队列；恢复完成前禁止上传。更多处理方法见[故障排查](/img/docs/troubleshooting/)。
