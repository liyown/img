本文介绍 img 0.4。主导航包括图库、上传、转换与压缩、尺寸与裁剪、存储源与设置。两个图片工具可独立使用，无需配置图床；详细操作见 [0.4 使用指南](/img/docs/0.4/)。

## 导入与上传

主窗口支持文件选择、拖放、剪贴板、截图和多行图片 URL。导入只加入待上传队列，点击「上传」才开始。每批在启动时固定存储源、处理选项与复制偏好。

真实传输进度来自请求体读取量；传输完成后显示等待确认，收到存储服务成功响应才标为完成。可暂停、继续、取消单项或整批，并重试失败项。暂停会终止请求，继续时重新上传文件，**不支持断点续传**。

## 图库与链接

图库合并桌面、CLI 成功上传及已索引的远端图片，支持网格和列表。搜索文件名、存储源或 URL，切换搜索和视图保留选择。点击缩略图可放大，Esc 关闭；复制图标直接复制当前格式链接。

复制可选择纯链接、Markdown 图片、Markdown 链接、HTML 和 BBCode。默认自动复制当前批次的成功链接，按导入顺序换行排列。清缓存只删除本机副本，保留图库和原文件；隐藏记录不删除远端图片；远端删除需单独确认目标与版本。

## 设置分区

| 区块           | 可以调整                                                   |
| -------------- | ---------------------------------------------------------- |
| 存储源         | 新增、编辑、测试、默认图床、凭据                           |
| 上传与图片处理 | 并发、重试、压缩、最大宽度、JPEG EXIF 清理、路径和同名处理 |
| 链接与剪贴板   | 复制格式、自动复制                                         |
| 应用偏好       | 快捷键与界面偏好                                           |
| 关于与更新     | 版本、诊断、添加 CLI 入口、手动检查更新                    |

支持中英文与深浅主题；存储源在侧边栏单独管理。设置保留缓存、同步、快捷键和更新等应用偏好。当前不提供标签系统。

## 窗口与快捷操作

关闭窗口或 ⌘W 会隐藏窗口，上传继续；⌘Q 才退出。上传中退出可选择等待完成或暂停并退出。菜单栏提供打开窗口、上传剪贴板、截图上传、暂停／继续和退出。

| 快捷键 | 行为                 |
| ------ | -------------------- |
| ⌘U     | 选择图片，加入队列   |
| ⌘V     | 从剪贴板导入         |
| ⌘⇧S    | 截图并加入队列       |
| ⌘F     | 搜索                 |
| ⌘B     | 收起／展开侧栏       |
| ⌘⌥U    | 全局：直接上传剪贴板 |
| ⌘⌥S    | 全局：截图并直接上传 |

全局快捷键可修改或关闭。快捷批次顺序执行，不会顺带上传尚未手动提交的图片。未设置默认源时保留导入内容并打开存储设置；取消截图不创建任务。每批结束后发送一条结果通知。

Windows / Linux 使用 Ctrl+Alt+U 和 Ctrl+Alt+S。Windows 支持区域截图与托盘；Linux Wayland 使用桌面门户，快捷键取决于 GlobalShortcuts 支持，托盘取决于 StatusNotifier。macOS 提供菜单栏后台入口。各平台验收边界见[迭代记录](https://github.com/liyown/img/blob/main/docs/iteration-0.4.md)。

## 安装、终端命令与更新

macOS 从 DMG 打开正式 Img.app 后，可拖入 Applications，或在「关于与更新」选择「安装到应用程序并重新打开」，后者安装到当前用户的 `~/Applications/Img.app`。开发与验收应用不提供此入口，请从[安装页](/img/install/#gui)获取正式包。

「添加终端命令」默认写入 `~/.local/bin`；已有其他 img 命令时不会覆盖。终端找不到命令时，将该目录加入 PATH，或选择独立 CLI 安装器。Windows 默认使用当前用户的 Programs/img 目录。

「检查更新」仅检查稳定桌面版本。下载后核验架构、大小和 SHA-256；无法验证时不会自动安装。社区包更新后仍可能需要系统允许打开。

## 本地数据与恢复

macOS 数据保存在 `~/Library/Application Support/aperture`，沿用历史目录保证升级保留。SQLite 图库由桌面与 CLI 共享；桌面队列仍由单个应用进程持有。图片缓存独立管理，默认上限 2 GiB；手动备份可选择包含缓存，跨设备同步始终不带图片文件。

队列串行原子保存，保留最近两份有效备份。发现损坏后先选择恢复备份，或保留损坏文件并重建空队列；恢复完成前禁止上传。更多处理方法见[故障排查](/img/docs/troubleshooting/)。
